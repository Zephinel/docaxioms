## owner 的补充：像生物的反射机制

Claude 的对应（供批评）：

| 反射弧 | 文档系统 |
|---|---|
| 感受器：察觉刺激 | 变化检测：code pin、段落哈希、git 差异、决策行状态变化、任务关闭 |
| 传入神经 | 依赖边（pin、落点、research→item、生成器输入） |
| 反射中枢（脊髓），就地决定，不等大脑 | 规则引擎：沿依赖图求受影响集合，按拓扑序排列 |
| 传出神经与效应器 | 动作：生成物重算落盘；散文标为待复核，可交 agent 起草 |
| 事后上报大脑 | 报告给人：自动做了什么、还剩什么要确认 |

两条由比喻得出的边界：反射只做固定、低风险的反应（生成物、行号平移、退役时的链接改写）；会改变含义的散文交给“大脑”（人或 agent 判断，A0、A6）。反射会习惯化：同一刺激反复出现而无后果，反应减弱，对应 A7 的误报疲劳，所以要精确、有提前截断。
